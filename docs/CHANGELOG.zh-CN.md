# 更新日志

## 1.3.0

这一版给小元素换上真正的超分模型，矢量导出只对简单图形开放，画板多了可编辑的基础矢量形状。

- **内置 Real-ESRGAN，高清修复完全离线**。安装包内置 Real-ESRGAN general x4v3（SRVGGNetCompact，1.21M 参数，4.8MB，BSD-3-Clause）和 ONNX Runtime Web。素材库的「✦ 高清」现在用模型跑：优先 WebGPU（约 0.55 秒 / 128px 图块，首次加载约 1.4 秒），显卡不支持时自动退回 WASM，全程不联网。保存时的自动高清仍走快速经典算法，设置 → 素材处理里可以单独关掉模型。实测 96×64 的贴纸：文字和圆形边缘明显更锐，经典算法 / 双线性放大则发虚。
- **矢量导出只对简单元素开放**。描摹前先判断是不是纯色扁平图（主色数量、半透明边缘占比）：logo、文字、线条和简单图形才会生成真正的 `<path>`；照片、渐变和复杂插画保留为内嵌 PNG；整批都没有可描摹元素时直接提示「没有简单的纯色图形」，不再输出一堆碎片。实测：简单 logo → 1 个矢量层、24 条路径、4KB、无 `<image>`；渐变照片 → 拒绝 / 回退。
- **画板新增基础矢量形状**。矩形、圆角矩形、椭圆、线条、箭头、三角形、星形共 7 种，可添加、选中、移动、缩放、旋转和导出；属性区能改填充 / 空心、描边颜色和宽度、圆角半径、星形角数。形状按导出分辨率重新绘制，放大不糊，也会随画板存档一起保存。

## 1.2.1

修 1.2.0 试用里反馈的画板 / 拆元素问题，并加上真正的 SVG 矢量化。

- **画板多选 / 成组可以整体缩放和旋转了**。选中两个以上元素时会出现整组选框，四角拖拽按比例缩放、顶部圆点旋转，位置和角度一起变；底部「角度 / 大小」滑杆也改成同时作用到所有选中元素（大小按同一比例、位置绕整组中心缩放）。
- **双击图层改名修好了**。Electron 不支持 `window.prompt()`，原来调用会直接抛错；现在换成应用内输入框。同时避开“点一下图层就重画列表、原生 dblclick 永远等不到”的问题，改成按两次点击的间隔判断。SVG 画布的图层改名同样修复。
- **拆元素的「加到当前 / 从当前减去 / 拆出一块」重做**。修了切换图块后仍用上一张图坐标、导致位置错乱的问题；没有显式选中时，直接作用在圈到的那个元素上（最上面一层）；结果会强制勾选，不会出现“改完看不见”；区域没有变化会明确提示；参数区显示当前元素名字。
- **横向 / 纵向等距**：只移动元素，不会新建文字；完成后提示「已等距分布 N 个元素」。
- **AI 反选更好懂**：新增「+ 选中点 / − 排除点」两个按钮，不再只靠 Alt；提示点更大、带白边，点下就画出来（模型下载失败也能看到自己点了什么）；图例写明绿 + 保留、红 − 排除，Alt 可临时反向。
- **素材库 / SVG 库默认不再显示勾选框**。标题栏新增「多选」，开启后才显示勾选框、框选矩形和批量删除栏；退出多选会清空选择。这样不会在没开多选时看到一个孤零零的方框。
- **新增「矢量 SVG」导出**：内置 ImageTracer.js（Unlicense / 公有领域）把选中的简单 logo、文字、线条和图形描摹成真正的 `<path>` 矢量路径，放大不糊，可直接用于 UI / 海报 / 高清修复；复杂或超大元素自动保留为内嵌 PNG，保证文件完整。实测 300×200 的 logo + 文字：3 个矢量图层、70 条路径、约 12 KB、无内嵌图片、可正常渲染。

## 1.2.0

这一版把「抠图增强、图层与特效、批量整理」一次补齐；画板多了「存档」，素材库支持框选批量删除。

- **拆元素：从选中元素再拆一块**。魔棒 / 套索 / AI 的工具模式新增「拆出一块」：圈中的部分变成独立元素，原元素只保留剩下的部分。
- **AI 点选支持反选**。点一下 = 选中，按住 Alt 点 = 排除这一点；可以连续点同一个物体反复修正，AI 会按全部提示点重新抠。画布上用绿 + / 红 − 标出提示点，参数面板显示正选 / 反选数量和「清空提示点」。
- **补画笔**。预览窗新增补画笔，和橡皮二选一：误擦或没抠到的像素可以刷回来。拆元素页改写蒙版，画板改位图，Ctrl+Z 可撤回；文字元素不能补画。
- **软边抠图（羽化）**。设置 → 素材处理里新增 0–6 px 软边：对 alpha 做羽化，并把半透明边缘的颜色往内部拉，减轻白边 / 黑边。实测同一元素：过渡像素 4291 → 6770，硬边像素 8054 → 6677。
- **自动文字 / 线条整理**。拆元素页新增「整理文字/线条」：细长条会认成线条，同一行、高度接近、间距很小的碎块会合并成文字块。只在你点按钮时执行，自动拆分不会偷偷合并。
- **批量一致性**。批量导入多张图后出现「全部重拆」，用当前这套参数把每张图重新跑一遍，避免逐张调参导致结果不一致。
- **分层 SVG 标注清楚**。从拆元素导出的 SVG 里，每个图层是内嵌 PNG 位图，不是矢量路径，放大仍会模糊。导出提示、按钮说明、SVG 库说明、SVG 画布标题都会标出「内嵌位图」，文件里也写了 `<desc>`。
- **画板图层面板**。右上角「图层」打开后真实占一列（画布跟着变窄）。每层可以显示 / 隐藏、锁定、双击改名；属性区可以调透明度和混合模式（正常 / 正片叠底 / 滤色 / 叠加 / 变暗 / 变亮），并支持成组 / 取消分组（点组内任一元素会整组拖动）。
- **文字特效 / 贴纸描边与投影**。同一套属性区可以给图片和文字加描边（宽度 + 颜色）和投影（模糊、X/Y 偏移、颜色），导出和存进素材库都会带上。
- **等距分布**。选中三个以上元素时，底部「横向等距 / 纵向等距」按实际像素边缘把间距均分（实测三个宽度不同的元素间距完全相同）。
- **画板「存档」**。把画布大小、背景、背景图、所有图层、文字和特效存到本机，下次从列表打开继续改；可以保存多个、可以删除。存在用户数据目录，升级不丢。
- **素材库 / SVG 库框选批量删除**。每张卡片右上角有勾选框，空白处拖动可以框选，Ctrl / Shift 点击加选；标题栏显示已选数量和垃圾桶按钮，删除仍有 3 秒撤回。

## 1.1.2

这一版是 1.1.1 试用反馈的修复和补充。

- **修复：用橡皮后整块背景像被擦掉了**。以前一落笔就把图层切成「手动蒙版」，边缘处理补出来的区域全部消失，看起来就像背景被整块擦掉。现在落笔前先把当前看到的蒙版固化下来，橡皮只擦笔刷经过的地方；实测 1459×928 的整图元素擦一笔只少约 7000 像素，远处像素保持不透明。
- **橡皮不再断断续续**。快速拖动时会在两个指针事件之间补点，笔迹连续；拆元素和画板预览都适用。
- **预览窗里可以撤回了**。Ctrl+Z（或标题栏的 ↶ 按钮）撤回上一笔橡皮：拆元素页恢复上一笔的蒙版，画板恢复上一笔的位图；撤回按钮会按有没有历史自动禁用。
- **新增「置底」按钮**。选框右下角加了向下的箭头，和多选时隐藏的「置顶」对应；单选时才有。
- **新文字沿用上一次的样式**。字号、字体、颜色、行高、字距、粗体/斜体、对齐都会记住，新加的文字默认用这套值；文字面板底部加了「恢复默认」，只有点它才回到初始值。样式记在本机，重启后还在。
- **画板左侧素材可以预览和删除**。每个素材卡片悬停显示放大镜和垃圾桶：放大镜打开和元素预览一样的窗（左侧缩略图、右侧大图，无勾选），垃圾桶删除并保留 3 秒撤回。素材库页也加了放大镜。
- **删除键统一用垃圾桶图标**：拆元素列表、画板、素材库、SVG 库 / SVG 画布的删除都换成图标，中英切换不用再猜文字。
- **SVG 画布旋转控件修正**。旋转柄改成从顶边中点伸出一小段，和画板一致，不再是左上角拉出的一根斜线；旋转后手柄跟着顶边方向走。
- **界面可以按区域调整了**（都是真实改布局，不是浮层覆盖）：
  - 拆元素页：舞台和右侧元素区之间可以左右拖，元素区变宽会多排几列。
  - 画板：左侧素材栏宽度可拖；素材卡片可以用标题栏的 − / + 或 Ctrl+滚轮缩放，显示更多素材。
  - 素材库：Ctrl+滚轮或右上角 − / + 调整卡片大小，一屏看更多。
  - 导航栏：左上角 ‹ 收起，收起后只剩 16px 的细条和 ›，主区域跟着变大。
  - 以上宽度和缩放都记在本机。
- **快捷键补齐 UI**：画板加了复制一份（Ctrl+D）按钮，拆元素页加了「收起」（Esc）按钮，预览窗加了缩放 − / +、适应和撤回按钮；主要快捷键都能在界面上找到对应操作。
- 1.1.1 里的吸附虚线、背景图、字体库、滚轮微调等保持不变。

- **元素预览可缩放、可擦除**。预览窗支持滚轮以鼠标为中心缩放、中键拖动平移、双击复位。顶部新增橡皮按钮，开启后底部出现橡皮大小滑杆，直接在预览上涂抹即可擦掉不要的部分：拆元素页改的是元素蒙版（导出生效，涂抹后自动按「手动图层」处理，不再被补洞填回来）；画板预览改的是画板里的位图副本（原素材库文件不动，可撤回）。

- 导入 / 下载字体走主进程保存到 `userData/fonts`，下载源固定 `registry.npmmirror.com`，不经过第三方脚本。

## 1.1.0

- **画板新增文字**：工具栏多了「文字」按钮，可以加文字图层。支持黑体 / 宋体 / 楷体 / 衬线 / 等宽等系统字体（不打包字体文件），字号、行高、字距、颜色、粗体、斜体、左中右对齐都能调；双击画布上的文字直接选中并打开面板改字。文字按参数矢量绘制，放大查看和导出成图都不糊（实测同一段文字在 2 倍画布上墨迹正好是 2 倍，边缘过渡带只有 2px）。
- **画板新增对齐**：底部多了一条对齐栏，左 / 水平居中 / 右 / 上 / 垂直居中 / 下六个方向，外加「居中」按钮（把选中元素放到画布正中）。基准可选「画布」或「选中元素」——选后者时多个元素会互相对齐。
- **对齐按实际有像素的边缘算**，不是按 PNG 图片的透明边。图片层先用 alpha 扫描出真实墨迹范围（最多采样 1024px 并缓存），文字层用 `measureText` 的紧致外框，旋转 / 缩放后取四个角的世界坐标。实测：一张 200×200、内容只占右下角 60×40 的图，左 / 右 / 上 / 下 / 水平居中 / 垂直居中分别精确落在 0 / 1080 / 0 / 1080 / 540 / 540，误差 0px；文字层的墨迹与计算外框误差 0.41px。
- **修复：反复导入 / 截图越来越卡**。以前每导入一张新图，上一批的 canvas 和像素数组都不释放，元素图层越积越多，元素列表每次点选都整块重画一遍。现在重新导入前会统一清空上一批的状态（释放 canvas、像素数据和缩略图缓存），元素列表在图层集合没变时只更新勾选和名字、不重建 DOM，套索重绘也合并到每一帧一次。
  - 实测（900×650、每张 8 个元素）：单张重新导入 104ms（旧版 443ms）；元素列表重画 20 次 3ms（旧版 1057ms）；反复导入 5 次后再重画 20 次 2ms（旧版 2427~7010ms）；堆内存稳定在 13MB（旧版 21MB 且随导入上涨）。
- **修复：重新导入后元素序号接着上一批数**（第二次导入从「元素 9」开始）。现在每次重新导入 / 截图 / 粘贴 / 清空画布，序号都从 1 开始。
- **修复：改「边缘平滑」开关没反应**，改「补缺口宽度」后缩略图有时还是旧的。现在两个设置都会同时作废补过边的蒙版和切好的透明底图并立刻重画（实测切换后缩略图哈希值确实变化，补缝宽度 0 → 6 时墨迹像素 19272 → 19476）。
- 顺手修掉了透明底图缓存写进孤儿对象、等于没缓存的问题（元素列表缩略图因此快了约 20 倍）。

## 1.0.7

- **修复：「从当前减去」看起来完全没效果**。手动画框或魔棒抠掉元素内部的细节（比如圆盘中间那块）之后，导出时边缘处理的「填洞」又把那块原样补了回来，等于白抠。现在只要是你亲手新建、加过或减过的图层，就不再自动补缝和填洞，减去立刻生效（实测：圆盘中心像素 alpha 从 255 变成 0）。
- **新增：元素放大预览**。每个元素卡片右下角多了一个放大按钮，点开是一个预览面板：左边一列长条缩略图，右边把当前元素放大来看（小图最多放大 3 倍，再大就是马赛克）。左侧可以用滚轮滑动，也可以按 ↑ ↓ / PageUp / PageDown 翻页；每项都带勾选框，和元素列表里的勾选状态是同一个；空格勾选当前元素，Esc 关闭。
- **新增：把素材库 / 画板素材栏的元素拖到「拆元素」再拆一次**。素材库的卡片和画板右侧的素材栏都可以直接拖到左侧导航的「拆元素」上，程序会把那张 PNG 读进来并自动重新拆解，方便在已经存下来的元素上继续抠细节。拖到别的栏目会提示「素材库里的元素只能拖到『拆元素』再拆一次」。
- 修复：预览面板打开时，空格和方向键会被拆元素页的「空格 + 拖动平移」手势抢走，导致翻页和勾选没反应。

## 1.0.6

- **修复：素材库卡片高度不齐**。竖长图和方图混在同一行时，竖长图会把缩略图盒子撑高，另一张卡片下方留出一大片空白。现在缩略图固定 1:1，卡片高度一致，图片在框内等比缩放居中。
- **新增：自动更新（Windows / Linux AppImage）**。设置里检查到新版本后可以直接「下载并安装」，下载进度会显示在按钮上，下好会提示「立即重启安装」，素材和设置都保留。macOS（未签名）和 deb / rpm（没有就地更新通道）仍然走「打开下载页」。下载必须由你点击触发，不会在后台偷偷拉安装包。
- **修复：批量导入时「剩下的部分也存成一层（背景）」只处理当前那张图**，其它图的剩余像素被静默丢掉。现在每张图各存一层，文件名带上原图名（`背景 - 元素 309.png`），不会再出现 `背景_2.png` 这种叫法。
- 文档：新增 [Linux 桌面环境支持情况](../README.md#linux-桌面环境支持情况)（X11 与 Wayland 逐项对照），并写清 Wayland 下「桌面环境截图 → 导入」的替代做法。

## 1.0.5

- **补缺口能力升级**：之前只能补 2px 以内的缝，现在新增「裂缝填充」——只在**两侧都有前景、且缝隙很窄**的地方把它接上，所以能把 3~4px 的断口、阶梯状的裂缝补回来（实测 1~4px 直缝 100% 补上，阶梯缝完全合拢），同时不会把两个离得远的元素粘成一个。
- 设置里新增「补缺口宽度」：可选手动放宽或收紧补缝的宽度（默认 4 px）。调得越大越容易把挨得很近的两个元素连成一个，按需取舍。
- 边缘平滑的实测效果：硬边原本只有 0 / 255 两级 alpha，现在边缘会有一圈渐变过渡（实测过渡像素从 0 变成 200 个），台阶状锯齿明显减少。

## 1.0.4

- **批量拆元素**：导入图片时可以一次选多张（按钮、拖拽都行），每张都自动拆开，所有元素汇总到一个列表里；点哪个元素就自动切到它来自的那张图。
- **拆元素页改成拼贴墙**：多张图统一缩放、按数量均分成网格铺在一张大画布上，当前操作的那块高亮，可以用滚轮缩放细看、拖动平移，整体一览再挑细节。
- **边缘平滑与补缺口（默认开启）**：导出时会自动补上边缘上的小缺口、填掉被完全包住的洞、把 alpha 过渡带抹平，边缘不再断断续续、也不会有台阶锯齿。纯本机算法，不联网、不加载模型；可在设置里关掉按原样输出。
- 左侧导航的 logo 改成按图标本身的几何重绘：橙色圆角方块里那圈白色虚线一直绕着中心圆点流动。
- 修复：切换界面语言后，SVG 画布还停留在上一种语言的文案。
- 修复：元素列表重画后滚动位置被弹回顶部（滑动后再点元素会跳回第一行），现在保持不动。
- 元素展示区改成更密的卡片网格，缩略图按侧栏宽度自动排布，空出来的空间被利用起来。
- 修复：一次导入多张图时，几张图会互相抢「当前正在拆的那张」，导致切出来的元素取错源图（红色图切出蓝色内容）。现在逐张排队处理，每张图拆完再拆下一张。
- 修复：程序在后台/隐藏状态下导入图片时，偶尔一直卡住不动（图片解码在窗口隐藏时不会返回）。
- 修复：还没打开过 SVG 时点左侧「SVG 画布」会直接崩掉。现在显示空状态，提示先导入 SVG，并给出「导入 SVG」「SVG 库」两个入口。
- 修复：元素列表滑动后点元素还是会跳回顶部——之前保存的滚动位置记在了外层容器上，真正滚动的是列表本身。现在列表停在原来的位置。
- 修复：元素名（元素 1 / Element 1）是在拆图那一刻按当时的语言定下来的，切了界面语言还是旧语言的写法。现在自动生成的元素名跟着语言变；自己手动改过名字的不动。
- AI 点选选了浮点版，但这台机器内存不够时会直接失败。现在会自动换回量化版重试一次，并提示已经换过。
